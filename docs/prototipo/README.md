## Figma de verdad (si quieren citar la herramienta)

Este HTML **se ve** como Figma; no es un `.fig`. Para escribir “prototipamos en Figma”:

1. Cuenta [Figma Education](https://www.figma.com/education/) con mail de ORT (gratis).
2. Nuevo archivo → 5 frames Desktop (1280×800).
3. Plugin [html.to.design](https://www.figma.com/community/plugin/1159123024924461424) → URL `http://127.0.0.1:5174`  
   o copiar cada frame desde Presentar (screenshot) y pegarlo en el frame.
4. Prototype: Acceso → Inicio → KPIs / Predictivo / Asistente.
5. Comments con los 4 puntos de validación del panel derecho.

Penpot (open source) sirve igual si no quieren Figma.
